# 信号系统模型(a0.13.0.0 · SINR 比值制)

> 适用版本:feat/satellite-v2 `b7af036` 起。旧版(a0.12.x)线性制描述已废弃,见文末差异表。

## 1. 实体与数据流

```
信号源 SignalSource(信道 1~5, 编码 4 字符)
   ├─ 覆盖半径 15 格内按归一化高斯广播原始强度(中心 15)
信号中继器 SignalRelay(绑定编码 → 转发同信道信号,15 格,级联同源链)
信号干扰器 SignalJammer(信道 1~5 或全频,同模型衰减的干扰功率)
卫星(真实单位,固化 编码+信道,覆盖圆内定值原始强度)
   ↓ 全部汇入
SignalChannel.effectiveAll(队伍, 点位)  ←— 唯一权威计算(绑定/激活/绘制共用)
   ↓
每信道: { 有效强度 eff, 最强来源 src, 干扰分母 I }
```

## 2. 强度模型(SINR 比值制)

**原始强度**(距离衰减,信号源/中继器/干扰器共用):

```
raw(d) = 15 · (e^(−d²/2σ²) − e^(−R²/2σ²)) / (1 − e^(−R²/2σ²)),  R=15 格, σ=6
```

归一化使 **R 处精确为 0**(旧版边缘 0.66 悬崖断环已消除),中心不变 15。

**有效强度**:

```
I   = 底噪(0.5) + 同信道异源功率和(CCI) + 邻信道泄漏(ACI) + 干扰器功率
SINR = best / I
q   = clamp((SINR − 1) / (SINR_REF − 1), 0, 1),  SINR_REF = 3.5
eff = best × q
```

| SINR | 状态 |
|------|------|
| ≤ 1(功率压不过底噪+干扰) | **无信号**(物理可检测的唯一定义;`eff > 0 ⟺ best > I`) |
| 1 → 3.5 | 质量线性 0 → 满 |
| ≥ 3.5 | 满质量(功率全额) |

**设计语义**:干扰压的是**信噪比**,不是从幅度扣功率——强信号天然抗弱干扰(15 强度源遇 2 强度干扰仍满质量;线性制下会被扣到 12.5),弱信号被任何干扰压死。

### 卫星层(同口径)

覆盖圆内单星原始强度:LEO 1.5 / MEO 1.3 / GEO 1.1 / SSO 1.5(固化信道受干扰;信道 -1 不受)。

```
单星有效 e = raw × sinrQuality(raw, 0.5 + 该信道干扰)
叠星(同编码): stackEff = max + ln(1 + Σ其余)   ← 对数叠星,最强全额
```

净空单星:LEO 1.2 / MEO 0.83 / GEO 0.53——**首星即过中继器激活阈值**;叠星边际递减但抗干扰裕度实质提升。

## 3. 合成

- **卫星 × 地面:RSS 功率合成** `total = √(g² + s²)`(覆盖绘制层)。卫星对已有地面覆盖的区域是**真实增益**,不再是取 max 的替补;着色归贡献较大一方。
- 绑定判定(`inSignalRange`)是布尔量:任一层可达即可,**无需合成**。
- **中继级联零衰减、卫星硬边覆盖圆(GEO 全图依赖)、对数叠星**为锁定设计,不改动。

## 4. 阈值体系(全部不变)

| 判定 | 阈值 | 说明 |
|------|------|------|
| 建筑绑定 | eff > 0 | ⟺ 功率 > 底噪+干扰(SINR > 1) |
| 中继器激活 | eff > 0.5 | 地面路径 = 源在 15 格内且供电;卫星路径 = satelliteStrengthAt > 0.5 |
| 上行门控 | hasLiveSource | 编码的地面源全灭 → 卫星停止广播(删源即断链) |
| 1:1 配对 | inGroundSignalRange | 中继与源同信道配对(地面) |

## 5. 频谱面板(信号源/中继器配置界面)

`SignalSpectrum`:本点 5 条信道 × {信道 | 占用(全队源/中继数 + 干扰器数) | 干扰 I−底噪 | 可用强度条}。
当前信道行高亮。15 tick 节流重算(与 H 覆盖同一次遍历)。是 SINR 制的**对策入口**:看哪条信道干净 → 切信道规避。

## 6. 与旧版(a0.12.x 线性制)差异

| 场景 | 线性制 | SINR 制 |
|------|--------|---------|
| 有效强度 | `max(0, best − (N0+CCI+ACI+干扰))` | `best × q(SINR)` |
| 边缘覆盖 | 0.66 悬崖归零 | 平滑精确归零 |
| 强信号 vs 小干扰 | 被等量扣减 | 满质量(SINR ≥ 3.5) |
| 卫星层 | 逐星扣干扰 → 叠星 → 末尾扣底噪 | 逐星 SINR 折算 → 叠星(底噪在质量因子内) |
| 覆盖显示 | max(地面, 卫星) | RSS 功率合成 |
